# Data

This project uses the 2025 Stack Overflow Developer Survey.

Official sources:

- Survey archive: https://survey.stackoverflow.co/
- Data repository: https://github.com/StackExchange/Survey/tree/main/packages/archive/2025

The raw survey data is licensed under ODbL 1.0 and its contents under DbCL 1.0.

## Local layout

- `raw/results.csv`: official raw survey responses; not committed by default
- `raw/schema.csv`: official survey question schema
- `processed/`: analysis-ready datasets generated by the project

The raw response file is larger than GitHub's normal single-file limit and is
not committed. From the repository root, run `python scripts/download_data.py`
to download both official files and verify their SHA-256 hashes.
